# AAA AI Apps 初回設定サポート申込マニュアル要約

## 1. 初回設定サポートの目的

AAA AI Apps の「ピックアップ信号機（公告マッチング AI）」は、企業ごとの以下の情報をもとに、公告との適合度を青・黄・赤で判定します。

- 入札資格・競争参加資格
- 国家資格・免許
- 健康診断・特別教育
- 過去の工事実績

自社プロファイルが未登録または不十分な場合、以下の問題が起こります。

- 対象外の公告を青判定する
- 本来応募できる公告を黄・赤判定する
- 等級不足や免許切れなど、自社固有の弱点を指摘できない

初回設定サポートでは、必要書類を AAA にまとめて送付し、運営側にプロファイル登録を代行してもらえます。

### 更新アラート

有効期限のある資格・免許・健康診断を登録すると、期限の以下の日数前にテナント管理者へメール通知されます。

- 90日前
- 60日前
- 30日前
- 7日前
- 当日

これにより、入札参加資格、各種免許、特殊健診、技能講習などの更新漏れを防ぎます。

## 2. 申込画面へのアクセス

1. AAA AI Apps にログインする  
   `https://aaa-ai-apps.com/`
2. 左側メニューから「初回設定サポート申込」を選択する
3. 申込フォームを開く

### 操作権限

- **テナント管理者（TENANT_ADMIN）**  
  申込、履歴確認が可能
- **一般メンバー（TENANT_MEMBER）**  
  申込履歴の閲覧のみ可能

## 3. アップロード推奨書類

書類は PDF または画像（PNG / JPG）で準備します。  
有効期限や取得日が記載された面を必ず含めてください。

### 撮影・スキャン時の注意

- 蛍光灯などの反射を避ける
- 書類全体が枠内に入るよう真上から撮影する
- 文字が潰れない解像度で撮影する
- 表裏がある書類は両面を添付する
- PDF 出力できる書類は、OCR 精度が高いため PDF を優先する

### 3-1. 入札資格・競争参加資格関係

最優先で登録する書類です。

| 書類 | 主に読み取る情報 |
|---|---|
| 経営事項審査結果通知書 | 業種コード、総合評定値、等級、有効期限 |
| 建設業許可通知書・許可票 | 許可業種、許可番号、許可年月日、満了日 |
| 入札参加資格認定通知書 | 発注機関ごとの認定業種、等級、登録地域 |
| 全省庁統一資格結果通知書 | A〜D 等級、営業品目、有効期間 |
| 指名業者登録通知書 | 登録業種、登録地域 |

複数の発注機関に登録している場合は、各機関分をすべて提出します。

住所、生年月日、本籍など、登録に不要な個人情報は黒塗りして構いません。

## 4. 申込フォームの操作手順

### STEP 1：ファイルをアップロード

ファイルをドラッグ＆ドロップするか、Finder・エクスプローラーから選択します。

#### 対応形式

`PDF / PNG / JPG / JPEG / GIF / WEBP / DOCX / XLSX / PPTX / DOC / XLS / PPT / TXT / CSV`

#### 上限

| 項目 | 上限 |
|---|---:|
| 1ファイルあたり | 50MB |
| 合計ファイル数 | 50件 |
| 合計サイズ | 300MB |
| 1日あたりの申込回数 | 10回 |
| 補足事項 | 4,000文字 |

#### ファイル名の例

```text
20240401_経営事項審査結果通知書.pdf
```

「日付＋書類名」で命名すると、登録作業や将来の差し替えがスムーズになります。

### STEP 2：補足事項を入力

任意項目ですが、以下の情報を書くと登録精度が上がります。

- 主要事業エリア
- 得意分野・重点登録希望業種
- 対応可能な特殊条件
- 更新中の書類
- 退職予定者や登録不要の資格
- 今後取得予定の資格
- 運営側への質問や希望

### STEP 3：申込を送信

「申込を送信」をクリックすると、アップロード処理が開始されます。

完了後、画面に `ots_` から始まるチケット ID が表示されます。  
通常は **1〜3営業日** で運営側が確認・登録し、完了メールが届きます。

## 5. 主な送信エラー

| エラー | 対応 |
|---|---|
| 申込はテナント管理者のみ実行できます | 管理者アカウントで操作する |
| 本日の申込上限に達しました | 翌日以降に再送する |
| ファイル内容と拡張子が一致しません | 元の正しい拡張子に戻す |
| 50MBのサイズ上限を超えています | PDFを分割するか画像を圧縮する |

## 6. 申込後の流れ

申込状況は、フォーム下部の「過去の申込履歴」で確認できます。

| 段階 | ステータス | 内容 |
|---|---|---|
| 申込送信 | なし | 管理者が送信した直後 |
| 受付済 | `pending` | 運営事務局が受付 |
| 対応中 | `in_progress` | 書類確認・代行登録中 |
| 完了 | `completed` | プロファイル登録完了 |
| 却下 | `rejected` | 書類不備などにより受理不可 |

通常は以下の流れです。

```text
pending → in_progress → completed
```

却下された場合は、理由を確認して修正後に再申込します。

### 完了後にできること

- 「設定 → 入札資格プロファイル」で登録内容を確認・編集
- ピックアップ信号機の判定精度向上
- 資格・免許・健診の更新アラート受信

アラートは登録されたテナント管理者全員に送信され、同じ項目・同じ期限での重複通知は抑止されます。

## 7. 再申込・追加申込

書類の漏れや新しい資格の取得があった場合、何度でも再申込できます。  
ただし、1日10件までです。

### 推奨運用

- **初回**  
  全書類をまとめて送信
- **更新時**  
  変更・追加した書類だけ送信
- **差し替え時**  
  補足欄に「これは差し替えです」と明記

例：

```text
経審を更新しました。
前回登録のR5年度版をR6年度版に差し替えてください。
```

登録内容をリセットする場合は、「設定 → 入札資格プロファイル」から個別に操作します。

## 8. FAQ 要点

### 申込ボタンが押せない

- テナント管理者権限を確認
- 一度ログアウトし、再ログインする

### 個人情報が含まれる

住所、生年月日、本籍などは黒塗り可能です。  
登録に必要なのは、主に資格名、取得日、有効期限、必要に応じて氏名です。

### ファイルの保存先

企業専用の Google Drive フォルダに保存され、運営担当者のみがアクセスします。  
他テナントとは分離されています。

### AI 学習への利用

マニュアル上では、Gemini API に送信した企業データはモデル学習に使用されない契約とされています。  
詳細は契約書面とプライバシーポリシーを確認します。

### 完了までの期間

- 通常：1〜3営業日
- 大量書類や繁忙期：最大5営業日の場合あり

### 自分で登録・編集したい

「設定 → 入札資格プロファイル」から手入力、追加、修正ができます。

### OCRで自動登録したい

同画面に Gemini を利用した自動読取機能があります。  
ただし、初回は精度や項目補完のためサポート申込が推奨されています。

### 更新アラート

期限を更新すると、新しい期限を基準に再度カウントされます。

### 退職者の資格

- 申込前：補足欄に登録不要と記載
- 登録後：入札資格プロファイルから該当資格を削除

## 9. 問い合わせ

| 内容 | 確認・連絡先 |
|---|---|
| 申込状況 | フォーム下部「過去の申込履歴」 |
| 書類の準備方法 | マニュアル第2章 |
| 操作・トラブル | `info@kk-aaa.com` |

問い合わせメールの件名例：

```text
【初回設定サポート】会社名・チケットID
```

メールには以下を添えると調査が早くなります。

- `ots_` から始まるチケット ID
- 画面のスクリーンショット
- エラーメッセージ全文
